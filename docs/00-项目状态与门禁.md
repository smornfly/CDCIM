### 5.2 WSL 侧（待用户执行后回填）

请在 WSL 终端执行，把输出贴回：

```bash
wsl -l -v                                  # 确认 VERSION 为 2
docker version && docker compose version   # Docker Engine + compose v2
free -h                                    # 内存总量（应为 8 GB 左右）
df -h /                                    # 可用磁盘（≥ 20 GB）
docker run --rm hello-world                # 镜像拉取与运行
```

同时确认 `C:\Users\scf\.wslconfig` 是否设置了：

```ini
[wsl2]
memory=8GB
swap=2GB
```

> 若未设置，WSL2 默认会占用宿主内存的 50%–80%，在多设备上表现不一致，必须显式限定。
