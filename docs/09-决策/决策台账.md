## 4. 决策记录规范

1. 任何新决策先在此表登记 D 编号，再决定是否需要单独 ADR（影响架构、影响多份文档、存在明显权衡的必须写 ADR）。
2. ADR 一旦定稿，**只追加、不重写**；方案改变时新建 ADR 并在旧 ADR 标注「被 ADR-000N 取代」。
3. 用户在对话中给出的口头决定，主智能体必须当日落入本表，不得只存在聊天记录里。
4. 论文写作时，「架构决策过程」段落直接取本表 + ADR 的「候选方案 → 约束 → 决策 → 代价」结构。
