# CDCIM · 金融业数据中心动力与环境智能监控系统

> 项目代号 **CDCIM**，系统全称 **金融业数据中心动力与环境智能监控系统（DCIM-EM）**。

**双重目标**

1. **工程目标**：在 WSL2 + Docker 上交付一套可运行、可演示、架构自洽的完整系统（采集 → 接入 → 计算 → 存储 → 告警 → 联动 → 可视化）。
2. **备考目标**：全程按软考高级「系统架构设计师」考纲组织设计与文档，产出可直接引用的论文素材，最终形成完整论文草稿。

**两条铁律**

- **文档先行**：P0–P3 全部为文档阶段，不写业务代码；文档不是附属品，文档就是交付物。
- **阶段门禁**：每个阶段交付后停下等验收，用户确认后方可进入下一阶段，绝不跨阶段。

## 技术主线（A 档 · 精简真栈）

| 层 | 选型 | 备注 |
|---|---|---|
| 采集 | 边缘模拟器 → Mosquitto(MQTT) | 真实场景为 Modbus/SNMP 网关，模拟器高保真替代 |
| 接入 | Redpanda（Kafka 协议兼容） | 单节点，替代 Kafka 集群，省内存 |
| 计算 | Python 消费者组 + 滑动窗口 | 替代 Flink；Flink 以 compose profile 按需启动 |
| 存储 | TDengine（时序）+ PostgreSQL（业务元数据）+ Redis（缓存） | 国产时序库呼应信创约束 |
| 智能 | 云端大模型 API（旁路）+ Qdrant（向量检索） | 脱敏后外发，可降级为纯规则 |
| 展现 | Vue3 + ECharts（2D 大屏）+ Three.js（3D 机房） | 浏览器侧渲染，不占 WSL 内存 |
| 部署 | Docker Compose，WSL2 ≤ 10GB | 两台设备同构，配置外置 |

选型理由与权衡见 [`docs/09-决策/`](docs/09-决策/)。
